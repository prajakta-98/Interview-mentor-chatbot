
========================================
ASSIGNMENT 1 - INTERVIEW PREPARATION MENTOR
========================================

1. CREATE VIRTUAL ENVIRONMENT

py -3.13 -m venv venv


2. ACTIVATE VIRTUAL ENVIRONMENT

.\venv\Scripts\Activate.ps1


3. UPGRADE PIP

python -m pip install --upgrade pip


4. INSTALL PROJECT DEPENDENCIES

pip install -r requirements.txt


5. CHECK INSTALLED LIBRARIES

pip list


6. DOWNLOAD THE CHAT AND EMBEDDING MODELS

ollama pull llama3.2
ollama pull nomic-embed-text


7. RUN THE CONSOLE APPLICATION

python main.py


8. RUN THE STREAMLIT WEB APPLICATION

streamlit run app.py


9. OPTIONAL MODEL CONFIGURATION

Set MODEL_NAME, EMBEDDING_MODEL, and OLLAMA_BASE_URL in .env to override the
defaults. The defaults are llama3.2 and nomic-embed-text.
